# 变更记录

## 0x01 0.1.0 — 2026-10-17

### a. Added

- 提供 Codex 和 Cursor CLI 执行器，通过 `/agent` 按会话切换并分别恢复上下文。
- 提供企业微信长连接和本地终端入口，共用会话控制、限频、取消与任务时限。
- 提供首次配置向导、无参数启动和短期私聊配对，自动记录用户白名单。
- 支持历史会话、模型选择、带附件重跑、入站附件和本地图片结果交付。
- 提供协议、进程、状态和官方企业微信 SDK 的自动化测试。

### b. Changed

- 使用 `agent-chat-bridge` 通用名称，以平台消息和 Agent 事件协议分离两侧实现。
- 执行器默认为只读配置，企业微信要求明确的用户白名单。

### c. Removed

- 移除 Claude 执行器及其专属配置和登录依赖。
