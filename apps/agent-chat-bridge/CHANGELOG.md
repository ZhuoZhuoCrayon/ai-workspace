# 变更记录

## 0x01 0.3.0 — 2026-10-23

### a. Added

- 提供管理员与使用者角色，以及模型之外的 `/whoami`、`/access`、`/allow` 和 `/deny`。
- 权限变更原子持久化，撤权取消运行任务，全局执行器和模型仅允许管理员修改。
- 提供独立 UID/GID 与 HOME，过滤执行环境，并在启动时检查管理配置、祖先目录和运行代码的权限边界。
- 提供受保护、固定字段、容量轮转的审计，覆盖消息接收、拒绝、权限变更和任务结果。
- 增加官方 SDK 授权集成、真实降权、冒充身份、引用隔离和会话边界回归。

### b. Changed

- 企业微信模式必须配置独立执行账号，已有白名单必须明确配置管理员，升级前按 `docs/security.md` 迁移。
- 每轮提示词明确自身权限与配置边界，图片回传按打开的文件描述符检查授权目录。

## 0x02 0.2.2 — 2026-10-23

### a. Fixed

- `/agent` 与 `/model` 写入状态目录中的全局偏好，私聊、群聊和不同用户共用。
- 各聊天的上下文和归档仍按会话分开保存。
- 旧会话文件没有全局偏好时，采用最近更新的执行器，并按执行器保留较新的模型。

## 0x03 0.2.1 — 2026-10-18

### a. Changed

- 空闲时限与总时限分别由 `idleTimeoutMs` 和 `hardTimeoutMs` 配置，默认 10 分钟与 60 分钟。
- 初始化配置显式保存两个时限，`/metrics` 返回当前进程加载的值。
- 旧 `timeoutMs` 继续作为绝对时限，新 `hardTimeoutMs` 优先。

### b. Fixed

- CLI 标准输出、工具事件与标准错误刷新空闲计时，持续工作的任务不会在 10 分钟时停止。
- 空闲超时、总时限与取消分别提示，完成或取消后清理计时器及 CLI 进程组。

## 0x04 0.2.0 — 2026-10-18

### a. Added

- `/agent` 和 `/model` 提供编号选择与企业微信快捷选项，模型按执行器独立保存。
- 每种执行器内置 `4` 个常用模型，默认使用 GPT-6.1 Sol High 和 Grok 4.7 Extra High Fast。
- 思考摘要和工具进度通过企业微信原生折叠区域展示，与正文分离。
- 支持本机人格文件，两种执行器共用自然、结论优先的表达方式。
- 聊天答复按信息关系组织短段、列表和步骤，引用区分团队网页、实际所属仓库与官方文档。
- 企业微信将本地文件文本链接降级为普通路径，避免交付无法打开的超链接。

### b. Fixed

- CLI 工具大结果按 JSON 令牌流读取，避免无须展示的 MCP 结果触发整行长度上限。
- 占位引用明确标记原文缺失，保留当前提问且不猜测原文。
- 人格约定与通道提示词使用短列表和结构表，拆开长句中的不同职责。
- Codex 固定使用 High 和标准速度，避免继承本机 Fast 配置。
- Cursor 开启增量输出，过滤重复文本，旧模型卡片不会误改另一执行器的模型。
- Codex 支持显式配置工具联网权限，避免宿主机 GitHub API 可用而沙箱内连接失败。
- Codex 支持显式选择 Full Access，过程旁白从最终正文中分离。

## 0x05 0.1.0 — 2026-10-17

### a. Added

- 提供 Codex 和 Cursor CLI 执行器，通过 `/agent` 按会话切换并分别恢复上下文。
- 提供企业微信长连接和本地终端入口，共用会话控制、限频、取消与任务时限。
- 提供首次配置向导、无参数启动和短期私聊配对，自动记录用户白名单。
- 支持历史会话、模型选择、带附件重跑、入站附件和本地图片结果交付。
- 提供协议、进程、状态和官方企业微信 SDK 的自动化测试。

### b. Changed

- 使用 `agent-chat-bridge` 通用名称，以平台消息和 Agent 事件协议分离两侧实现。
- 执行器默认为只读配置，企业微信要求明确的用户白名单。

### c. Removed

- 移除 Claude 执行器及其专属配置和登录依赖。
