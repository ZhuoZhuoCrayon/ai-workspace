# APM 日志存储支持切换 ES 集群

## 0x01 背景

APM 日志存储页只读展示集群名称，应用管理者无法直接切换集群，而配置接口已有对应能力。
目标是在该页面完成 ES 集群选择、校验与保存，并正确刷新存储信息。

## 0x02 实现路线

复用既有日志存储配置协议，补齐前端交互，详见 [精简方案](./PLAN.md)。
范围限于 APM 管理的 OTLP 日志 ES 集群切换，保留无损切换及历史数据过期清理语义。
