# Code Style

## 0x01 核心

- 优先读取目标项目的 `AGENTS.md` 与 `CONTRIBUTING.md` 等文档，收集可能存在的项目级代码风格规范。
- 如果项目规范与工作区规范冲突，以项目规范为准。

## 0x03 交付证据

- 说明本次命中的规则来源。
- 如涉及代码修改，说明规则如何体现在改动中。
