# Humanizer 中文改写示例

## 0x01 技术说明与操作指南

| 原句 | 改写 |
| --- | --- |
| 系统具有对导入文件进行校验的能力。 | 系统会校验导入的文件。 |
| 如果您需要帮助确认失败原因，可以考虑查阅错误日志。 | 要确认失败原因，请查看错误日志。 |
| 该策略可能潜在地对结果产生一定影响。 | 该策略可能影响结果。 |

## 0x02 报道与事实介绍

| 原句 | 改写 |
| --- | --- |
| 画廊设有四个独立空间，拥有超过 3,000 平方英尺的展览面积。 | 画廊有四个展厅，总展览面积超过 3,000 平方英尺。 |
| 统计局成立于 1989 年，这标志着区域统计史上的关键时刻。 | 统计局成立于 1989 年。 |

## 0x03 评审与工作短评

| 原句 | 改写 |
| --- | --- |
| 非常好的建议，确实有必要进一步明确超时值的单位。 | 请在超时值旁标明单位。 |
| 产品发布之后，下一步将安排后续会议讨论用户反馈。 | 产品发布后，团队会开会讨论用户反馈。 |

## 0x04 个人随笔与评论

原句把作者的犹豫写成了泛泛的评价。

> 对于一夜生成的三百万行代码，我既印象深刻，又对它的价值持保留态度。

改写保留第一人称，把犹豫落到作者关心的问题上。

> 一夜就写了三百万行，我很惊讶。可这些代码有多少值得留下，我还说不准。
