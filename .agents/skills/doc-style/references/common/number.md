# 数值

## 0x01 数字形式

- 阿拉伯数字使用半角形式：不使用全角形式。
- 数值为 `4` 位以上时添加千分号：千分号用半角逗号，例如 `1,258,000`。
- `4` 位数千分号选用：`1000` 和 `1,000` 都可接受。

## 0x02 货币

- 货币使用阿拉伯数字：数字前写货币符号或数字后写货币中文名称。
- 英文货币名称参考 ISO 4217 标准：例如 `$1,000`、`1,000 美元`。

## 0x03 数值范围

- 数值范围用波浪线 `～` 或一字线 `—` 连接。
- 范围两端带单位或百分号时两个数字都加：例如 `132 kg～234 kg`、`67%～89%`。

## 0x04 变化程度表示

- 增加用"增加了"或"增加到"：「了」表增量，「到」表定量。
- 减少用"降低了"或"降低到"：「了」表增量，「到」表定量。
- 减少不能用倍数：用"降低百分之几"或"减少百分之几"，不写"降低 N 倍"或"减少 N 倍"。

## 0x05 工作区约定

- 文档中出现的关键阈值数字加反引号：例如 `120`、`3`、`5` 等约束数字，便于审查工具识别。
