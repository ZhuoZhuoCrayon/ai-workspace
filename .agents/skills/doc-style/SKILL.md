# Doc Style

**用最少但充分的信息，帮助目标读者看懂重点、作出判断或完成行动；正文、图表和注脚都按这个目标取舍。**

## 0x01 写作与交付

1. 明确读者需要回答的问题或完成的动作，据此取舍材料。调查经过只在读者需要复现或理解原因时保留。
2. 开头同段给出结论和关键理由。提出建议时，说明哪项事实支持这项选择，以及哪些条件会改变它。
3. 交付前逐节试删正文、图表和注脚。操作说明保留读者照着就能完成任务的最小示例，删去复述示例的文字和字段表。
4. 通读成稿，核对事实、适用边界、职责与来源，交付可独立使用的完整文本。
