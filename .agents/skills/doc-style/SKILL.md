# Doc Style

**用最少但充分的信息，帮助目标读者看懂重点、作出判断或完成行动；正文、图表和注脚都按这个目标取舍。**

## 0x01 写作与交付

1. 明确读者需要回答的问题或完成的动作，据此取舍材料。调查经过只在读者需要复现或理解原因时保留。
2. 开头同段给出结论和关键理由。涉及验证时，写清实际检查的对象和观察到的结果，把仍需验证的判断放在结论旁。
3. 交付前逐节试删正文、图表和注脚。操作说明保留可照用的最小示例。判断取决于条件时，用同一例子改变一个关键条件，让读者看出结果为何随之改变。
4. 从读者视角通读成稿，核对事实、职责和来源，删去复述，交付可独立使用的完整文本。
